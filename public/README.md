# Tentaflake artwork

Project logos, illustrations, and wallpapers. Use of the name and logo follows
the [trademark policy](../TRADEMARK.md).

| Asset | Files | Purpose |
|---|---|---|
| Animated overview | [SVG](tentaflake-overview.svg) | README banner: a typed TOML example in a dark Neovim-style editor with embedded Cascadia Mono. Animation ends after five seconds and respects reduced motion. |
| README illustration | [JPEG](tentaflake-readme.jpg) | Original static artwork. |
| Shell logo | [Text](tentaflake-shell-logo.txt) | Braille artwork loaded by the [contributor shell](../lib/devshell.nix). |
| Logo wallpaper | [PNG](tentaflake-wallpaper-16x9.png) | Standard wallpaper. |
| Dark logo wallpaper | [PNG](tentaflake-wallpaper-16x9-dark.png) | Dark wallpaper variant. |
| 3D wallpaper | [Original](tentaflake-3d-realism-logo-wallpaper-16x9.png), [smaller version](_compressed/tentaflake-3d-realism-logo-wallpaper-16x9.png) | Illustrated logo and agent mascots. |
| Operator shell | [SVG](tentaflake-operator-shell.svg) | README terminal: the shell logo as a vector dot matrix beside current `tentaflake status`, `doctor` and `doctor --security` output on a synthetic host. |

The animated banner and operator shell embed Cascadia Mono from Microsoft Cascadia Code v2407.24,
redistributed under the [SIL Open Font License](LICENSE-Cascadia.txt).
